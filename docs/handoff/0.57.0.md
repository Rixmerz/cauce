## 6. Mejoras descubiertas (para tareas nuevas)
1. **Concurrencia:** cauce lanzó ~24 suites a la vez. Limitar los checks pesados por repo (cola o semáforo)
   y que el estimado de duración use la carga real.
2. **"timed out after the claimed pass" no debería escalar el modelo.** Es ambiental: debería quedar
   `blocked environment` y reintentar el check, no subir sonnet → opus ni terminar en `replan`/`failed`.
3. **Una tarea `dismiss` no debe perder el worktree** (#2170 perdió sus cambios). Conservar la rama.
4. **Resultado ilegible:** varios intentos fallaron con "did not answer with exactly one result block".
   Revisar el formato pedido o tolerar el bloque repetido.
5. `cauce resume` con `--allow` es bloqueado por el clasificador cuando lo lanza el agente
   (automodificación): documentar que lo corre la persona.
6. #2065 (pendiente, en cola tras #2050): layout-inspector no mide pantallas con login; reutilizar la
   sesión del navegador (perfil rastro) para entrar.
7. Tests que dependen del PATH del host (`rastro` instalado): ya arreglado en main (`3b349ed`); vigilar que
   nuevos tests usen el fixture.
